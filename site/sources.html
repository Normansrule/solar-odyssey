How we check sources

  1. Primary sources first. We cite the peer-reviewed paper, the agency's own dataset or report, the standard, or the original patent. Encyclopedias and news stories are a last resort and are labelled as such.
  2. Every link is resolved. Each DOI and URL was opened and read to confirm that it exists and says what we cite it for. The date of that check is shown as “verified”.
  3. Fast-moving numbers carry dates. Records, prices and capacities change every year. On the page they carry a “Last verified” date and point to State of the field.
  4. Datasets are signed. Every data file the site loads is listed with its size and SHA-256 hash in a manifest signed with an Ed25519 key. Pages refuse data that fails the check and say so.
  5. Worked examples are recomputed. Every worked example names the function that reproduces it, and the test suite recalculates it on every change.

Found a mistake, a dead link or a better source? Please open an issue on the project's GitHub repository (the Issues tab of this site's repository) with the page, the claim and the source you suggest.
